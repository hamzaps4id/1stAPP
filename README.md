# ساعة جدتي — Grandma Clock

تطبيق أندرويد بسيط يعرض ساعة عقارب كبيرة وواضحة، مع إبقاء الشاشة مضاءة أثناء تشغيل التطبيق.

## المزايا
- ساعة عقارب وليست رقمية.
- أرقام/علامات كبيرة وواضحة ومناسبة لكبار السن.
- ملء الشاشة.
- يمنع التطبيق الشاشة من الانطفاء أثناء تشغيله.
- لا يحتاج إلى إنترنت أو حساب.

## ملاحظة مهمة
هذا التطبيق يبقي الشاشة مضاءة أثناء فتحه، وليس Android Always-On Display النظامي الذي يظهر فوق شاشة القفل عندما يكون الهاتف مقفلاً. تختلف إمكانية AOD حسب الشركة المصنعة للجهاز.

## البناء
يمكن بناء APK عبر GitHub Actions من تبويب Actions.
